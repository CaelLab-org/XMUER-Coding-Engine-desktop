隐私权政策
虚舟实验室承诺尊重每一位用户的基本人权。关于我们的价值观与信念，请参阅 人权原则。

我们收集的信息
我们仅在为您提供服务所必需的范围内收集信息。以下为收集的信息类别，具体项目因服务而异，并不限于所列内容：
您提供的信息

- 注册信息：邮箱地址、密码（经加密存储）、昵称、头像、个人简介，以及部分服务要求的出生日期、性别、所在国家/地区等；

- 您主动发布的内容：主题帖、回复、评论、上传的文件等；

- 您与我们沟通时提供的信息：通过邮件或反馈渠道发送的咨询、投诉、建议等。

我们自动收集的信息

- 设备与网络信息：IP 地址、浏览器类型及版本、操作系统等；

- 使用数据：访问时间、页面浏览记录、点击行为、停留时长、来源页面等；

- Cookie 及类似技术：用于维持登录状态、记录功能偏好、避免重复提示等。Cookie 仅在实现其功能所需的期限内有效，到期自动失效。

来自第三方的信息

- 当您通过第三方账号或授权方式使用我们的服务时，我们可能获得您授权共享的基本信息（如用户标识、昵称、头像等）。

我们如何使用信息
我们使用收集到的信息仅用于以下目的：

- 提供服务：验证身份、维持登录状态、展示您发布的内容、实现社区互动功能；

- 优化体验：分析使用数据以改进网站性能、修复故障、优化界面布局与功能设计；

- 安全防护：识别异常访问、恶意刷屏、垃圾信息、自动化攻击等行为，保护平台及用户安全；

- 合规与沟通：响应法律法规要求或有权机关的合法请求，处理您的咨询、投诉与反馈。

我们不会将您的信息用于营销、广告推送或用户画像分析，也不会出售您的个人信息。

我们如何共享信息
我们严格限制信息共享，仅在以下情形下向第三方提供您的信息：

- 获得您的明确同意：在事先征得您同意的前提下，向指定第三方共享信息；

- 服务提供商：向为我们提供技术支持、服务器托管等服务的合作方共享必要信息，且要求其遵守同等隐私保护标准；

- 法律法规要求：在法律法规强制要求或有权机关依法提出请求时，配合提供必要信息；

- 权益保护：为保护虚舟实验室、我们的用户或公众的合法权益免受侵害，在必要范围内披露信息。

- CDN 与网络服务：我们使用 Cloudflare 为 *.caellab.com 及 caellab.com 提供网络分发、安全防护及性能优化服务。Cloudflare 可能收集访问请求中携带的网络信息（如请求日志、IP 地址、浏览器类型等），用于安全分析、威胁检测及网络性能优化，这些信息由其依照自身隐私政策处理。详见 Cloudflare 隐私政策。

您享有的权利
根据本政策及适用法律法规，您对自己的个人信息享有以下权利：
知情权
您有权了解我们收集了您的哪些信息、如何使用这些信息、与谁共享这些信息。本政策及平台各自的隐私政策即为此而设。
访问权
您有权访问我们持有的关于您的个人信息。大部分信息可通过登录账号后在个人设置页面直接查看。
更正权
如果您的个人信息有误或发生变化，您有权要求我们更正。您可以直接在账号设置中修改昵称、头像、简介等信息；其他信息更正请求可通过 contact@caellab.com 提出。
删除权（被遗忘权）
您有权要求我们删除您的个人信息。您可以通过以下方式行使删除权：

- 自行删除：登录后删除您发布的内容、清空个人资料；

- 申请注销账号：通过各平台指定的注销渠道提交申请，我们将在 7 个自然日内处理。

请注意，受技术架构限制，部分历史数据（如已被其他用户引用或系统备份中的内容）可能无法完全删除，但我们将通过匿名化或脱敏处理，确保其不再与您个人关联。
限制处理权
在特定情况下，您有权要求我们限制对您的个人信息的处理，例如当您对信息的准确性提出异议时。
可携带权
您有权以结构化、通用、机器可读的格式获取您提供给我们的个人信息，并有权将这些信息传输至其他服务提供者。
反对权
您有权随时反对我们将您的个人信息用于特定目的（如用于安全分析之外的用途）。
撤回同意权
如果您之前同意我们处理您的个人信息，您有权随时撤回该同意。撤回同意不影响撤回前已进行的处理活动的合法性。

我们如何保护您的信息
我们采取合理的技术与管理措施保护您的个人信息：

- 加密传输：通过 HTTPS 协议加密数据传输，防止中间人攻击；

- 加密存储：密码等敏感信息采用哈希加密存储，无法逆向还原；

- 访问控制：严格限制内部人员对用户数据的访问权限，仅必要岗位可接触；

- 数据最小化：仅收集提供服务所必需的信息，避免过度收集；

- 定期审查：定期审查数据处理活动，确保符合本政策及安全标准。

信息保留期限
我们仅在实现收集目的所必需的期限内保留您的个人信息：

- 账号活跃期间：您的注册信息、个人资料及发布内容将保留至您主动注销账号或长期不活跃为止；

- Cookie：仅在实现其功能所需的期限内有效，到期自动删除；

- 日志信息：服务器访问日志仅在保障安全与排查故障所必需的期限内保留；

- 注销后：账号注销后，我们将在合理期限内删除或匿名化您的可识别个人信息，法律法规要求保留的除外。

儿童隐私保护
部分服务（如 CaelLabID）在注册时会收集出生日期与性别，用于判断用户是否未成年，并据此提供相应保护。本政策所称儿童，指未满 16 周岁的用户；如您所在地区法律法规对儿童的年龄标准另有规定，则按当地标准执行。如您属于上述儿童范围，请在监护人指导下使用我们的服务，并由监护人协助完成注册；注册 CaelLabID 时需提供监护人邮箱，由我们向监护人发送同意确认邮件。
我们不会将儿童的个人信息用于本政策约定之外的其他用途。如果我们发现在未取得监护人同意的情况下收集了儿童的个人信息，将立即删除，如需帮助请联系 contact@caellab.com。

跨境数据传输
虚舟实验室的服务器可能部署在不同地区。您的信息可能在您所在地区以外的服务器上进行存储和处理。无论数据存储在何处，我们都将按照本政策所述的保护标准进行处理，并确保传输过程符合适用的数据保护要求。

政策更新
我们可能会根据法律法规变化、业务调整或技术更新修订本政策。修订后的政策将在本页面公示，并在各平台显著位置提示更新。

- 重大变更：如涉及信息使用目的、共享范围或用户权利的实质性调整，我们将通过弹窗、邮件或站内通知等方式告知您；

- 一般更新：如涉及措辞优化、结构微调，我们将直接更新本页面并标注最新修订日期。

继续使用我们的服务即视为您同意修订后的政策。如您不同意，请停止使用并注销账号。

XMUER Coding Engine 隐私政策
================================================================
适用范围
本政策适用于 XMUER Coding Engine 的网页版（engine.xmuer.online）与桌面客户端，由虚舟实验室（CaelLab）发布，
与《虚舟实验室隐私权政策》共同适用、不可分割；两者如有冲突，以《虚舟实验室隐私权政策》为准。

我们不建立账号，也不收集个人信息
本引擎没有账号体系，不要求登录，也没有广告追踪、埋点或崩溃上报组件。你的项目、AI 对话记录、设置与 API 密钥
只保存在你自己的设备上（网页版保存在浏览器本地存储，桌面版保存在本机用户数据目录），虚舟实验室没有权限读取，
也不会在你的设备之外保存任何副本。

数据何时会离开你的设备
仅在你主动使用下列功能时。本引擎基于 TurboWarp / Scratch 构建，其中一部分行为沿用上游：

- AI 对话：请求由你的设备直接发送到你自行配置的 AI 供应商（服务地址与密钥由你填写），不经过虚舟实验室中转
  或存储，对话内容与密钥受该供应商的隐私政策约束。AI 需要查看你的项目（脚本、造型、舞台画面等）时，
  这些内容也会随请求发给你配置的供应商。

- AI 联网搜索：搜索关键词会发送到虚舟实验室运营的 CaelLab Search（caellab.click），
  按《虚舟实验室隐私权政策》处理。

- AI 读取网页：引擎按你（或 AI 应你的要求）指定的网址直接访问目标网站，目标网站可获知这次访问来自你的网络；
  抓取到的内容会放进对话上下文，随即发给你配置的 AI 供应商。

- 云变量：使用云变量时，项目 ID 与用户名可能被服务器记录 14 天。引擎默认连接 TurboWarp 的云变量服务器
  （wss://clouddata.turbowarp.org），项目也可以指定其他云变量服务器（不受我们控制）。云变量中的数据是公开的，
  会同步给同一时间连接的其他用户。

- 加载项目与浏览量：从别的网站加载项目时适用那个网站的隐私政策（例如从 Scratch 加载时适用 Scratch 隐私政策）；
  从 Scratch 加载时，项目 ID 还会作为走通 Scratch API 的一环发给 TurboWarp，可能被短暂记录用于缓存。
  网页版运行来自 Scratch 的项目时可能记一次浏览用于累计浏览量，浏览记录匿名、无法对应到具体的人，
  可在隐私政策页面取消勾选关闭。

- 扩展：部分扩展需要访问外部 API 才能工作（例如翻译、文字转语音依赖 Scratch API），请求内容与结果可能被
  TurboWarp 的 API 缓存。扩展访问未受信任的网站时通常会征求同意，但这不能保证百分之百可靠；从网址或本地
  文件加载自定义扩展时编辑器会先询问，同意后该扩展可绕过官方扩展的权限提示。

- 桌面客户端与打包器：XCE Desktop 会请求检查更新（可在「设置 → 桌面设置」关闭）；
  XMUER Coding Packager 会在浏览器里保存设置，并缓存 Electron 之类的大文件。

滥用防护与聚合统计
服务被滥用时，我们可能收集必要信息来保护服务（例如记录请求量异常的 IP 地址），并在滥用停止后尽快删除。
我们也可能记录匿名的聚合数据，例如某个站点每天的使用人数。

儿童
本引擎面向包括青少年在内的学习者设计。我们不收集个人信息，儿童可以在监护人指导下使用；
配置 AI 供应商这类涉及第三方服务的操作，建议由监护人协助完成。

政策更新
本引擎的功能变化若影响数据处理方式，我们会在版本发布说明中说明，并同步更新 https://engine.xmuer.online/privacy 上的公开版本。
